# Companion Mobile App for a Fitness Studio

## Context
In 2023, a growing fitness studio approached me to create a mobile experience that would keep members engaged, simplify class bookings, and provide personalized workout tracking. The studio’s existing digital touchpoints were limited to a basic website, and they needed a dedicated app that could handle real‑time class schedules, push notifications, and secure user data. My role as a full‑stack developer was to design and deliver a solution that would work seamlessly on both iOS and Android platforms while leveraging the studio’s existing tech stack.

## What I built
I built a cross‑platform mobile application using JavaScript and a modern front‑end framework, integrating tightly with Firebase for authentication, real‑time database updates, and cloud messaging. The app features:
- **Class scheduling** with live availability pulled from the studio’s API, allowing members to book or cancel spots instantly.
- **Personal workout logs** where users can record exercises, set goals, and view progress charts.
- **Push notifications** powered by Firebase Cloud Messaging to remind users of upcoming classes and special promotions.
- **Secure user accounts** managed through Firebase Authentication, ensuring data privacy and smooth sign‑in experiences.
- **API integration** with the studio’s existing backend to sync membership details, class capacities, and payment information.

The development process emphasized performance and a clean UI, ensuring quick load times and an intuitive navigation flow. I also set up continuous deployment pipelines to streamline updates and maintain high availability.

## Results
After launch, the app quickly gained traction, achieving a 4.7‑star rating on both the Apple App Store and Google Play Store. Within the first few months, it attracted **3,000 monthly active users**, surpassing the studio’s initial target. The high rating reflected user satisfaction with the smooth booking process, reliable notifications, and the ability to track workouts on the go. The studio reported increased class attendance and higher member retention, attributing these improvements to the convenience and engagement the app provided.
