# Course Platform with Video and Quizzes

## Context
In 2023, an education client approached Sara Malik, a full‑stack developer specializing in React, Next.js, and Node/Django back ends, to create an online course platform. The client needed a scalable solution that could host video lessons, deliver interactive quizzes, and manage user authentication for a growing student base. The project required integration with modern web technologies and cloud services to ensure reliability and performance.

## What I built
Sara designed and implemented the platform using **Next.js** for the front‑end, delivering a fast, SEO‑friendly experience for learners. The back end leveraged **MongoDB** for flexible content storage and **Amazon Web Services** for hosting, media streaming, and scalable compute resources. A robust **user authentication** system was built to securely handle registrations, logins, and access control for paid courses. Video content was stored on AWS S3 and streamed via CloudFront, while quizzes were dynamically generated from MongoDB collections, providing immediate feedback to students. The architecture emphasized modularity, allowing new courses and features to be added with minimal friction.

## Results
The platform launched successfully and attracted **1,200 paying students in the first term**, demonstrating strong market demand and effective user experience. The combination of Next.js and AWS ensured low latency and high availability, while MongoDB’s schema‑less design facilitated rapid content updates. Sara’s implementation delivered a reliable, scalable solution that met the client’s educational goals and set the foundation for future growth.
