# Restaurant chain P&L dashboard in Google Sheets

## Context
Bilal Ahmed was engaged by a hospitality client that operates nine restaurant locations. The owner needed a clear, up‑to‑date view of each outlet’s profit and loss performance on a weekly basis. The existing process involved manual data pulls from point‑of‑sale systems, spreadsheets that were updated sporadically, and a lot of time spent reconciling figures. The client wanted a single source of truth that could be shared with managers, required minimal manual effort, and would refresh automatically so that decisions could be based on the latest numbers.

## What I built
Bilal designed a centralized reporting workbook that pulls raw transaction data from the various locations, cleans and consolidates it, and then calculates key financial metrics such as revenue, cost of goods sold, labor expense and net profit. The solution uses built‑in functions to connect to the source files, merge them together, and reshape the data into a tidy format. Once the data is ready, Bilal created a series of visual elements—tables, bar charts and line graphs—that show weekly trends for each branch and allow quick comparison across locations. Interactive slicers let users filter the view by branch or by week. All calculations are driven by formulas that update automatically whenever the source data changes, eliminating the need for manual copy‑pasting. The workbook is stored in a shared cloud folder, so every stakeholder can view the latest dashboard without needing special software.

## Results
The new dashboard delivers a weekly profit and loss snapshot for all nine restaurants without any manual intervention. Data is refreshed automatically, reducing the reporting workload from several hours each week to virtually zero. Managers now have immediate access to accurate financial performance, enabling faster, data‑driven decisions such as adjusting staffing levels or promotional pricing. The client reported a noticeable improvement in operational efficiency and greater confidence in the numbers presented to senior leadership.
