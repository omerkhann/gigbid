# KPI Dashboard for a Solar Installer’s Field Teams

## Context
In 2025, a solar installation company needed better visibility into its field operations. The client, operating in the energy sector, struggled with an opaque install backlog and inconsistent install times across its teams. Management required a single source of truth that could be accessed by field supervisors and executives alike, enabling data‑driven decisions to improve efficiency and customer satisfaction. The existing reporting process relied on disparate Excel files and manual data pulls, which were time‑consuming and error‑prone.

## What I built
I designed and delivered an end‑to‑end Power BI solution that integrated directly with the company’s SQL database. The core components included:

- **Data model**: A robust SQL‑based data model that consolidated install orders, team assignments, and completion timestamps. I applied best‑practice data‑cleaning techniques to ensure accuracy.
- **Interactive dashboard**: Using Microsoft Power BI, I created a user‑friendly dashboard featuring:
  - A real‑time backlog view per field team, displayed as a bar chart with drill‑through capability to individual job details.
  - A KPI card showing average install time, automatically updating as new data arrived.
  - Filters for date range, region, and team, allowing stakeholders to slice the data as needed.
- **Automation**: Scheduled data refreshes ensured the dashboard reflected the latest operational data without manual intervention.
- **Training & documentation**: I conducted a short training session for the client’s analysts and provided a concise user guide to promote adoption.

## Results
The Power BI dashboard transformed the client’s reporting workflow:

- **Visibility**: Install backlog became instantly visible for each team, eliminating guesswork and enabling proactive resource allocation.
- **Performance improvement**: Average install time decreased by 1.5 days, a direct result of teams focusing on bottlenecks highlighted by the dashboard.
- **Time savings**: Manual Excel consolidation was reduced from several hours per week to a few clicks, freeing analysts to focus on deeper insights.
- **Adoption**: The intuitive design led to rapid adoption across field supervisors and senior management, fostering a data‑driven culture.

Overall, the solution delivered measurable operational efficiencies and set a foundation for future analytics initiatives within the organization.
